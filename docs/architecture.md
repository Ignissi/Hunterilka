# Архитектура системы

## Обработка и рабочее место

![Архитектура Hunterилки: два уровня анализа, PostgreSQL и рабочее место AML](assets/architecture.svg)

Первый уровень — CatBoost для отдельных операций по предшествующей истории. Второй — поиск связанных структур и Isolation Forest для оценки их необычности. Поиск структур не отсекается порогом первого уровня. Оценки относятся к разным объектам и формируют отдельные очереди рассмотрения.

`run_inbox` принимает новые законченные минуты. `run_stream` воспроизводит подготовленную историю для демонстрации. Оба используют один сервис, одни признаки, модели и запись результатов. Сервис получает события без меток, рассчитывает оценки и сохраняет случаи.

## Граница одной минуты

1. Удалить из графа события за пределами окна.
2. По предыдущему состоянию рассчитать признаки всех новых операций и оценки CatBoost.
3. Добавить операции, найти структуры и рассчитать оценки Isolation Forest.
4. Сохранить операции, векторы, оценки, случаи и позицию в одной транзакции PostgreSQL.
5. Для файлового входа подтвердить файл переносом в `processed`.

При ошибке SQL-запись откатывается, состояние в памяти сбрасывается и восстанавливается из БД перед повтором. При остановке после фиксации БД повтор последней минуты проверяет совпадение её содержания.

## Хранилище

| Таблица | Данные |
|---|---|
| `transactions` | Операции рабочего окна, оценки и векторы признаков |
| `cases` | Текущие карточки и снимки оснований |
| `case_versions` | Предыдущие версии случаев |
| `reviews` | Журнал решений, комментариев и времени |
| `stream_state` | Режим, источник, модель, параметры и последняя сохранённая группа |

Сохранённые карточки содержат собственный снимок и не исчезают вместе с исходными операциями из окна. Данные для обучения и файлы моделей хранятся отдельно от рабочей БД.

## Условия эксплуатации

Назначение, роли, жизненный цикл разработки и связь требований с проверками: [traceability.md](traceability.md).

Один процесс записи на рабочую БД. Источник передаёт завершённые минуты в порядке времени и использует уникальные идентификаторы. Граф находится в памяти; поиск структур ограничивается настройками бюджета. Доступ, резервное копирование и связь с АБС задаются при развёртывании. Корпоративная аутентификация и автоматическое переобучение не реализованы.
