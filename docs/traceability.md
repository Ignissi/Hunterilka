# Требования и проверки

| Требование | Реализация | Проверка |
|---|---|---|
| Проверять CSV и сохранять идентификаторы | data | Схема, ведущие нули, повторные строки, фильтр и некорректные суммы |
| Не использовать будущее | features, pipeline | Будущие строки не меняют ранние признаки; одинаковое время имеет одно прошлое |
| Поддерживать скользящую историю | graph | Частичное и полное истечение связей, независимое истечение часа |
| Рассматривать новые операции без предпочтения первых строк | patterns | Кольцо, замкнутое операцией после первых 128 строк |
| Не использовать разметку в поиске | patterns | Изменение приложенных меток не меняет кандидатов и признаки |
| Ограничивать вычисления воспроизводимо | patterns | Число просмотренных записей; одинаковый отбор при перестановке группы |
| Сохранять результаты без потери комментариев | cases | Повторное чтение, версии, сохранение решения при обновлении |
| Не вытеснять операции структурными аномалиями | review_queue | Отдельные списки; порядок не меняется при изменении меток |
| Различать место в очереди и пороговый сигнал | cases, evaluate | Карточка ниже порога допускается только при явном выборе по месту |
| Обновлять интерфейс без переобучения | refresh_review | Повторный прогноз совпадает с отчётом; модели и признаки сохраняются |
| Ограничивать экран | visualization | Лимит вершин и связей, отсутствие внешнего CDN |
| Не показывать будущее в окружении случая | snapshot | Отсечение будущих и истёкших переводов, в том числе при несортированном входе |
| Различать переводы одной пары | visualization | Отдельные рёбра для основания и контекста, инспектор операций |
| Отображать все поддерживаемые формы | visualization | Семь форм, сохранение всех рёбер основания в малых примерах |
| Сохранять решение при смене оформления | workspace | Перенос последнего статуса и комментария по ID случая |
| Не превышать validation-бюджет на равных оценках | metrics | Проверка порога при совпадающих оценках и малом наборе |
| Записывать признаки порциями | build_features | Сохранение пустых числовых значений и схемы Parquet |
| Проверять GPU до большого расчёта | check_environment | Пробное обучение; GPU-проверка выполняется на целевой машине |
| Воспроизводить оценки и восстанавливать позицию | check_replay | Сверка сохранённой таблицы и повторного прохода |

Команда компонентных проверок: `python -m unittest discover -s tests -v`.
Технические примеры в тестах не используются для обучения или оценки качества.

Ручная приёмка на целевой машине: открыть случай, проверить читаемость графа, выбрать операцию, рассчитать SHAP, сохранить решение, скачать экспорт и открыть приложение повторно. Автоматическая проверка через Streamlit AppTest не заменяет оценку читаемости в браузере.
