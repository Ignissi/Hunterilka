# Изменённая выборка IBM AML

Поставщик: IBM / Erik Altman. Источник: https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

Лицензия данных: CDLA-Sharing-1.0, https://cdla.dev/sharing-1-0/.

**Эти файлы изменены:** отобран хронологический банковский профиль HI-Small,
поля нормализованы, операции сгруппированы в случаи, добавлены оценки моделей.
Карточки выбраны по форме и оценкам без использования метки.
Демо является выборкой результатов, а не полной очередью и не отдельным тестовым набором.
Номера строк и значения операций позволяют сверить их с исходным CSV.
